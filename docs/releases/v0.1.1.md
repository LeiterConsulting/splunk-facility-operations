# Facility Operations 0.1.1

Settings now discovers models for the selected LLM method, supports model capability checks and configures reasoning effort for direct provider connections. The investigation assistant uses the official OpenAI Responses function-calling workflow and Ollama's native tool/thinking contracts.

[Download the `.tar.gz` installer](https://github.com/LeiterConsulting/splunk-facility-operations/releases/download/v0.1.1/splunk_facility_operations-0.1.1.tar.gz) · [Install or upgrade](https://github.com/LeiterConsulting/splunk-facility-operations/blob/v0.1.1/docs/getting-started.md#download-and-install-from-github) · [Assistant setup](https://github.com/LeiterConsulting/splunk-facility-operations/blob/v0.1.1/docs/assistant-setup.md)

## Changes

- **Refresh available models** queries OpenAI account models, Ollama's installed models or AI Toolkit's configured LLM connections. Refresh uses draft connection details without saving them. Manual identifiers remain available.
- **Check selected model capabilities** inspects Ollama's advertised tool and thinking support. A catalog entry is not a successful function-calling qualification.
- **Reasoning policy** offers adaptive, provider default and fixed low/medium/high choices for direct OpenAI/Ollama connections. Unknown or unsupported controls use provider defaults. Toolkit settings remain connection-managed.
- OpenAI uses strict function schemas, sequential tools and preserved original response items, including assistant phase and encrypted reasoning. Ollama preserves native assistant thinking internally between tool results. AI Toolkit can select a named connection.
- **Model calls and resource use** shows per-turn duration, applied reasoning and available token counts. Raw thinking and credentials stay out of diagnostics and exports. Incomplete/refused/limited responses and invalid toolkit JSON produce actionable errors.
- The setup and troubleshooting guides cover discovery permissions, provider contracts, model qualification and reasoning limits, with official documentation references.

## Installation

The app declares version **0.1.1**, build **7**, ID `splunk_facility_operations`. The `.tar.gz` and `.spl` assets are identical compiled installers; `SHA256SUMS` covers both. Upload the named installer through **Apps → Manage Apps → Install app from file**. A source build is optional.

Before upgrading, back up app settings, credentials through your approved procedure, and any live inventory. The release excludes local overrides and ships an empty live inventory. Select **Upgrade app** when replacing an existing installation, follow Splunk's prompts, then check Demo and Settings. Existing provider configuration is preserved; new reasoning settings default to Adaptive.
