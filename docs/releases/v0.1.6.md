# Facility Operations 0.1.6 — guided click-through presentations

Presenters can now follow an operations story without memorizing where the next dashboard change appears. The default demo holds a normal baseline; **Start guided walkthrough** opens a pinned guide that advances the scenario and brings each stage's evidence into view.

## Experience

- Eight contextual steps cover baseline, first signal, business impact, dependency, assistant investigation, decision, partial recovery and verification across all sixteen industries and six use-case families.
- Next/Back and numbered steps control the story. A highlighted evidence area, desktop arrow and concise source-backed summary make the change visible. Presenter notes provide more context. The workspace scrolls inside the native Splunk frame.
- The assistant step prepares a scoped question. **Investigate** explicitly starts the saved provider; the guide then reveals its activity/response and waits for completion or Stop before enabling step changes. Entering the step never starts inference automatically.
- Decision-to-recovery navigation previews synthetic data. It does not grant approval or execute a plan. Deliberately reviewed simulations retain their existing policy gates.
- **Download story evidence** retains normalized observations, capture times and SPL from stages actually visited. Restart clears the previous walkthrough's snapshots. Assistant reports and evidence remain separate downloads.
- Exit/Finish keeps the current phase paused. **Play continuous loop**, manual phase controls and free workspace exploration remain available. Applying another presentation ends the current guide; Live mode removes it.
- Stage navigation waits for complete matching Splunk results and offers a retry on failure. Compact layout, reduced motion, keyboard controls, workspace detours and cleanup are covered by browser checks.

See the [presentation guide](https://github.com/LeiterConsulting/splunk-facility-operations/blob/v0.1.6/docs/demo-guide.md) for the click-through sequence, troubleshooting and optional continuous playback.

## Installation

App ID **splunk_facility_operations**, version **0.1.6**, build **14**. Download **splunk_facility_operations-0.1.6.tar.gz** from the release assets and upload it compressed through **Apps → Manage Apps → Install app from file**. The `.spl` installer contains identical bytes. No source build, Node or npm installation is needed on the Splunk server.

For upgrades, back up local configuration, credentials and any populated live inventory. The shipped inventory is header-only. Select **Upgrade app**, follow Splunk's deployment/restart prompts and reopen the app. Saved provider settings were preserved on both verified labs. Follow the [installation guide](https://github.com/LeiterConsulting/splunk-facility-operations/blob/v0.1.6/docs/getting-started.md#download-and-install-from-github).
