# Facility Operations 0.1.2

Facility Operations now runs inside Splunk Web's native chrome, with Splunk UI Toolkit controls framing the operations workspace and investigation assistant. This release presents the app as a Splunk proof of concept and an art-of-the-possible demonstration.

[Download the `.tar.gz` installer](https://github.com/LeiterConsulting/splunk-facility-operations/releases/download/v0.1.2/splunk_facility_operations-0.1.2.tar.gz) · [Install or upgrade](https://github.com/LeiterConsulting/splunk-facility-operations/blob/v0.1.2/docs/getting-started.md#download-and-install-from-github) · [Presentation guide](https://github.com/LeiterConsulting/splunk-facility-operations/blob/v0.1.2/docs/demo-guide.md)

## Changes

- Splunk Web supplies its real bar, app navigation, account controls and Search page around the React workspace. The custom Mako template and imitation Splunk header are removed. A standard Simple XML 1.1 extension host supports the two qualified Enterprise versions.
- **Open current search in Splunk** opens the same bounded evidence search in this app's native Search context, with the signed-in user's permissions.
- Workspace navigation and Demo/Live selection use Splunk UI Toolkit buttons. Shared workspace links, browser Back/Forward and keyboard skip focus are supported. **Present** keeps Splunk chrome visible.
- Audience, industry and use case remain in Settings. Commercial and public sector stories, repeating demo evidence, governed simulations, provider model discovery and the investigation/export workflow remain available.
- Guides and screenshots now show the installed app. The standalone build is explicitly labeled **Developer component preview**; native demonstrations use the installed Splunk app. Contributor guidance records the UI boundaries and required installed checks.

## Installation

App ID: `splunk_facility_operations`. Version **0.1.2**, build **8**. The `.tar.gz` and `.spl` assets are identical compiled installers. Upload the named installer through **Apps → Manage Apps → Install app from file**; keep it compressed. No source build, Node.js or npm is required to install it.

Before upgrading, back up local configuration and populated live inventory, and follow your credential backup procedure. Select **Upgrade app** for an existing installation and follow Splunk's deployment prompts. Reopen the app and check its native navigation, Demo replay and Settings. This package excludes local overrides and ships an empty live inventory; follow the linked guide to preserve configured inventory. Custom app Mako enablement is no longer required by this entry view.

Remaining notices concern SplunkJS telemetry, Python migration, cluster configuration replication, Cloud role compatibility and traditional package identity. Real model inference, customer sources, production scale, Cloud/GovCloud, clusters and other platform versions need separate qualification.
